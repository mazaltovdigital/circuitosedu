# CircuitosEdu ⚡
**Produto Educacional de Mestrado: Ensino de Circuitos CA mediado por IA e Realidade Aumentada**

O **CircuitosEdu** é um Ambiente Virtual de Aprendizagem (AVA) desenvolvido como parte da pesquisa de mestrado de Daniel Sandoval. O projeto integra Inteligência Artificial (Gemini API) e Realidade Aumentada para atuar como um "andaime pedagógico" no ensino de Circuitos de Corrente Alternada.

## 🎯 Objetivos Pedagógicos
* **Aprendizagem Significativa**: Conectar conhecimentos prévios de eletricidade com novos conceitos de fasores e impedância.
* **Andaime Pedagógico**: Utilizar a IA para mediar o processo de descoberta do aluno, sem fornecer respostas diretas.
* **Interatividade Imersiva**: Uso de simuladores PHET e Realidade Aumentada (SENAI Space) para visualização de fenômenos eletromagnéticos.

## 🛠️ Tecnologias Utilizadas
* **Frontend**: HTML5, CSS3 (Roboto Font), JavaScript.
* **Backend**: Python 3.x, Flask, Flask-CORS.
* **IA**: Google Gemini Pro/Flash API.
* **Análise de Dados**: Google Analytics (Logs de Uso).
